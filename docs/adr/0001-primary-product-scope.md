# Primary Product Scope: B2B Agency Write-Execution Firewall

NexAd's MVP is the B2B Agency Write-Execution Firewall — a safety-gated middleware allowing autonomous agents to mutate ad campaigns with deterministic policy enforcement and HITL approval. Consumer agent negotiation (Use Case 1 in the use case spec) is out of scope for the product; a Simple Consumer Test Agent is in scope only as an internal QA harness to exercise the full MCP tool contract before production launch.
